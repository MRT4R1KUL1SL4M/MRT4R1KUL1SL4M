## 🎓 Research Projects & Publications

### 🩺 1. Automated Detection and Classification of Renal Abnormalities using a Hybrid Deep Learning Framework and XAI
*   **Status:** 🟡 Active Research
*   **Summary:** Developing a hybrid deep learning framework for automated renal CT image classification using Explainable AI (Grad-CAM and SHAP) to improve model transparency and clinical interpretability.

### 🚗 2. A Hybrid AI-Based Architecture for Vehicle Safety and Accident Prevention in Bangladesh
*   **Status:** 🟡 Working Paper
*   **Summary:** Developing a computer vision-based intelligent transportation system for real-time vehicle and hazard detection under complex road conditions in Bangladesh.

### 🫀 3. An Interpretable Hybrid Artificial Intelligence Framework for Automated Cardiovascular Disease Diagnosis
*   **Status:** 🟡 Working Paper
*   **Summary:** Architecting an interpretable clinical decision support system (CDSS) for early cardiovascular risk prediction, focusing on quantitative feature importance to verify algorithmic predictions against clinical guidelines.

### 🚨 4. Automated Detection of Fake Job Advertisements in Bangladesh via Machine Learning Approaches
*   **Status:** 🟢 Accepted & Published (Taylor & Francis)
*   **Summary:** Developed machine learning models for detecting fraudulent online job advertisements in Bangladesh. The work was presented at the ECCT Conference and published in an international Taylor & Francis book series.

### 🧠 5. Sentiment Analysis & Classification Optimization using Machine Learning
*   **Status:** 🟡 Under Review
*   **Summary:** Evaluated text preprocessing pipelines and hyperparameter tuning strategies to optimize multi-class sentiment classification performance.
